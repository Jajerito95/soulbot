# SoulSeeker™ — Guía rápida para usuarios

¡Bienvenido a SoulSeeker! Aquí tienes todo lo que necesitas sin líos. Solo comandos de **usuario** (sin permisos).

### 1) Primeros pasos
- `/code` → vincula tu cuenta de Minecraft con el código de `/code` en el server
- `/color` → elige tu color de nombre (uwu)
- `/card` → mira y personaliza tu tarjeta de nivel

### 2) Niveles y XP
- Chatea y entra a VC para ganar XP (automático)
- `/level` → tu nivel y barra de progreso
- `/leaderboard` o `/lb` → top 10 del server
- `/rewards` → qué rol te dan por subir de nivel

### 3) SoulCoins (Economía)
- `/daily` → 100-250 coins cada 24h
- `/work` → elige **minero** (pica 5 rocas) o **pescador** (pesca) — 1.000-1.500 coins cada 30m + bonus veloz
- `/works status` → mira tus cooldowns
- `/balance` → tu cartera o la de otro
- `/pay @user 100` → paga a un amigo
- `/richest` → top 10 ricos
- `/shop` → tienda (roles, boosts XP, XP instantánea)
- `/buy 1` → compra por ID

### 4) Misiones diarias 5/5
- `/misiones ver` → 5 misiones diarias (mensajes, voz, work, minijuegos, etc.) con barra `▰▱` . Pulsa el botón 📦 para reclamar caja sorpresa
- `/misiones reroll` → 1 reroll gratis al día si no te gustan
- Bonus si completas 5/5 → caja épica +500 coins +300 XP

### 5) Minijuegos (gana coins)
- `/coinflip 100 cara` → apuesta cara/cruz
- `/slots 50` → tragaperras
- `/trivia` → pregunta random
- `/tictactoe @amigo` / `/connect4 @amigo` / `/rps @amigo` → reta sin apuesta

### 6) Voz TTS
- Entra a un VC y **habla en el chat de texto** → el bot se auto-conecta y te lee (primer mensaje dice tu nombre, los siguientes solo el texto)
- `/vc tts texto:hola` → hazlo hablar a mano
- `/vc voices` → lista 7 voces (Alvaro, Elvira, Arnau, Dalia, Jorge, Elena, Tomas)
- `/vc voice alvaro` → cambia voz (ej. `dalia` para MX)
- `/vc leave` → que se vaya

### 7) Tickets y Ayuda
- Usa el panel de tickets (select) en #soporte
- `/ticket fcreate` → crea ticket rápido
- `/ticket close` → cierra tu ticket
- `/ticket adduser @amigo` → añade a alguien
- `/ticket commands` → ayuda

### 8) Comunidad
- `/suggestion tu idea` → sugiere algo
- `/invites count` → tus invites
- `/appeal create` → apela una sanción
- `/emoji list` → lista emojis
